# LeetCode #136 - Single Number

## Problem
Given a non-empty integer array `nums`, every element appears twice except for one element. Return the single element.

## Example

Input:
```text
nums = [2,2,1]
```

Output:
```text
1
```

Input:
```text
nums = [4,1,2,1,2]
```

Output:
```text
4
```

## Approach
- Pick one element.
- Count how many times it appears in the array.
- If the count is `1`, return that element.

## Time Complexity
- O(n²)

## Space Complexity
- O(1)

## Language
- Java

## Topics
- Array
- Brute Force
- Counting
